### 一、专业工具——Git&Github
#### 1、Git基础
>什么是Git？
Git是一个分布式版本控制系统，能记录每次代码的改动，方便回溯、协作和防止代码丢失。(即保存代码进度)

>版本控制？
1、Git会记录每一次代码的变更，可以轻松查看所有历史记录
2、Git可以创建独立的分支，在分支上可以自由地进行实验
3、Git可以自动合并一个团队中所有人对同一文件的修改，并且给出冲突部分
4、通过查看提交记录，可以有效解决bug

>4个核心命令：(终端命令行)
git clone:将远程仓库的代码克隆、复制到本地
git add:将文件改动添加到暂存区
git commit:将暂存区的改动正式提交到本地仓库
git push:推送至远程仓库

#### 2、数据上云
>什么是HTTP GET请求？
1、HTTP：超文本传输协议(unsafe)
2、GET：HTTP协议中的一种请求方法，用于"获取"数据
3、即用于提取数据，如查看网页、读取传感器数据
4、本题中用于将ESP32采集的温湿度数据通过URL参数的形式发送到ThingSpeak云平台，实现数据的远程存储和可视化。

>新增的这个功能，和之前的LED、DHT11一样，需要：
1、导入<HTTPClient.h>库
2、为了后续构建URL，先配置Thingspeak,包括API密匙宇thingspeak官网名
3、定义好thingspeak的初始时间和时间间隔
4、接下来，是最关键的数据上云函数——data_to_thingspeak()

>4.1、首先，在if语句判断wifi连接成功的前提下，发送HTTP请求
4.2、构建thingspeak API的URL,顺序依次为：HTTP协议开头、thingspeak的官方网址(前面已经配置好)、它的数据更新接口与API密匙参数、温度数据、湿度数据
4.3、终于，构建好URL后，可以发送HTTP GET请求
4.4、问了问AI，它帮我补充了这两个数据上传结果处理与反馈部分，在实际使用场景中可以帮助我们快速知道系统运行的状态
4.5、最后，关闭HTTP连接并释放内存！

5、在loop函数中，同样使用if语句，来实现数据每隔30s上传一次
